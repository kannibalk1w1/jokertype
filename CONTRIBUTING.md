# Contributing to JokerType

Thanks for helping make typing in Obsidian more playful.

## Local setup

1. Fork the repository and create a focused branch.
2. Run `npm install`.
3. Run `npm test` and `npm run build` before opening a pull request.
4. For visual changes, test in a desktop Obsidian vault with both light and dark themes when possible.

## Good contributions

- Keep effects optional and respect the reduced-motion setting.
- Avoid network access, telemetry, and new permissions.
- Add or update tests for behavior changes.
- Keep pull requests focused and explain the user-visible result.

## Reporting bugs and ideas

Use the issue forms to include your Obsidian version, JokerType version, and concise reproduction steps. Screenshots or short recordings are especially helpful for visual effects.
