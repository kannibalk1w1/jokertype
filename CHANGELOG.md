# Changelog

## 1.3.0

- Added the Full Deck: note embeds (`EMBEDDED`), callouts (`SUMMONED`), closed code blocks (`LOCKED IN`), footnotes (`CITED`), closed frontmatter (`DEALT`), and table divider rows (`GRID!`).
- Added individual Markdown Moment toggles and Off, Essentials, Full Deck, and Custom deck selections.
- Migrated the previous Essentials setting to the new per-Moment configuration.

## 1.2.0

- Added opt-in Markdown Moments for completed headings (`TITLE!`), wiki links (`LINKED`), new tasks (`QUEST`), and checked tasks (`CLEARED`).
- Added a card-style Moment effect that respects all visual themes, reduced motion, sound settings, and large-paste throttling.

## 1.1.0

- Added the Prism theme, which gives each typed glyph a stable jewel color while retaining clear colors for Enter, Tab, paste, and delete actions.
- Added the Prism preset: colorful, bracketed feedback with no editor shake and a visible combo counter.

## 1.0.1

- Added custom sounds for typing, Space, Enter, Backspace/Delete, and paste.
- Added controls for maximum pitch, pitch rise, and pitch reset delay.
- Added the `Toggle JokerType` command for assigning a hotkey.
- Hid the status item when the combo counter is disabled.

## 1.0.0

- Added HyperType-style pixel glyph particles for letters, space, enter, tab, backspace, delete, and paste.
- Added sampled HyperType-inspired typing sounds with rising pitch during fast streaks.
- Added presets: Subtle, Classic, Chaotic, and Sound only.
- Added visual themes: Arcade, Neon, Monochrome, and Terminal.
- Added sound style, volume, glyph lifetime, effect intensity, and reduced-motion settings.
- Added per-effect toggles for text glyphs, enter effects, delete effects, corner brackets, editor shake, and status combo counter.
- Added a Test effect button in settings.
- Added large paste throttling for smoother performance.
- Added mobile and reduced-motion friendly fresh-install defaults.
